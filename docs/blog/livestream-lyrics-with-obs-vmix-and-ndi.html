Livestream lyrics with OBS, vMix and NDI

How a transparent lyrics overlay reaches OBS, vMix or an NDI receiver, what each path needs, and how to set it up with Vifug without a capture card.

You have a camera, a switcher and a Sunday service to put online, and the words of the songs live on a different computer from the one making the stream. The usual first answer is a capture card: send the projector feed into the streaming PC and key it. It works, but it is one more cable, one more box to fail, and you get the lyrics at whatever the projector resolution happens to be. There are cleaner ways to get words onto a stream, and they all start from the same idea: the lyrics are a transparent layer that your video software places on top of the camera.

This post walks through the three common paths, a browser source in OBS or vMix, NDI over the network, and the capture-card fallback, and says what each one needs. Vifug is used as the worked example because it produces both the browser overlay and a native NDI source, but the thinking applies to any lyrics software.

What a transparent overlay actually is

A normal projector output is a picture of a slide: a background, some words, maybe a video loop. A stream overlay is different. It is a page with nothing behind the words, so when your video software draws it above the camera, you see the camera everywhere except where there is text. That is what lets you show the pastor and the first line of the chorus in the same frame.

Two consequences follow. First, the overlay should not carry its own busy background, because the background will cover your camera. Second, the layer has to sit above the camera in the stack, since video software draws from the bottom up.

Path 1: a browser source in OBS or vMix

This is the lowest-effort route and it needs nothing but the free software you probably already run. Your lyrics program serves a web address, and OBS or vMix loads it as a web page with a transparent background.

With Vifug the steps in OBS are:

  1. In Vifug, open Settings, then Streaming & output, and set the Stream canvas to the size your OBS canvas uses: 1920x1080 for a normal stream, 1080x1920 for a vertical one. Vifug lays the overlay out at exactly that size, so a lower third lands in the same place whatever size the source ends up.
  2. In OBS, choose Sources, then the plus button, then Browser.
  3. Paste the address from Stream / OBS source in the same settings page. There is a copy button beside it.
  4. Set Width and Height to match the canvas you chose. Leave the background transparent.
  5. Do not tick "Shutdown source when not visible". If you do, the overlay reconnects every time you change scene.
  6. Drag the browser source above your camera in the Sources list.

That last step catches almost everybody once. If the lyrics have vanished, the overlay is almost certainly sitting underneath the camera. Vifug also has a Teleport to OBS option in the same settings page that adds the source for you, which saves the copy and paste.

vMix works on the same principle: add a web browser input with the same address and layer it over the camera input. Match the resolution, keep the background transparent, and put the overlay on a higher layer than the camera.

Path 2: NDI over the local network

NDI sends video across a normal wired network, with no capture card and no extra cable run. If your vMix machine, your streaming PC and your lyrics computer are all on the same network, the lyrics can appear as a source in the switcher, listed by name, like a camera.

Two things to know about NDI before you plan around it:

  • It is a local network protocol. It does not travel over the internet. Every machine that needs to see the source has to be on the same network.
  • It likes a wired connection and a decent switch. Wi-Fi can work for a lightweight test, but a live service is not the time to find out how crowded the building's wireless is.

Vifug's desktop app can publish the output as a native NDI source, and the guide describes this as a feature of the desktop app, not the browser version. You enable it in Settings, under Streaming & output. Vifug's guide also describes an indirect route that works even when the lyrics are hosted in a browser: let OBS load the stream address, then use an NDI plugin in OBS to send that onto the local network. OBS can then be the machine that emits NDI for the rest of the building.

Path 3: the capture card fallback

Sometimes the overlay is not an option: the stream machine is a locked-down hardware encoder, or the switcher takes only HDMI. Then you feed the projector output into a capture card and key it in the switcher, or you simply let the lyrics fill the shot.

This works, with trade-offs. You are limited to the card's resolution, you need a card and a cable for every feed, and a keyed lyrics feed has to be designed with a solid, high-contrast background so the key is clean. If you can use a browser source or NDI instead, you will probably be happier.

Design the text for video, not for a wall

Words that look fine on a projector can be hard to read in a corner of a phone screen. A few practical rules for overlay text:

  • Use a heavy weight. In the Vifug theme designer, weights of 600 to 700 read well, and an outline of 2 helps text stay legible over a bright shirt or a stained-glass window.
  • Keep the lines short. Two lines per slide is enough for a lower third. Three or four lines start to hide the person you are filming.
  • Set a fixed font size for stream themes. Auto-fit is right for full-screen slides, but a lower third looks odd if the size jumps between a short line and a long one. A size around 56 on a 1080p canvas is a sensible place to start.
  • Check it at phone size. Open your private test stream on a phone held at arm's length.

The timer, the announcement ticker and your logo also show on the stream overlay, so remember that anything you leave switched on in the room can appear on the broadcast. Check the live output before you go to air.

A test routine before the first Sunday

  1. Build the scene with the overlay above the camera and press Go live in the lyrics software with a song cued.
  2. Walk through a song, a Bible verse and a blank. Blank should clear the overlay completely.
  3. Stream privately for five minutes to an unlisted or "Only me" event on YouTube or Facebook, then watch it back.
  4. Check audio sync, steady frame rate, and that the text is readable on a phone.
  5. Change scene a few times. The overlay should stay connected, not flash or reload.
